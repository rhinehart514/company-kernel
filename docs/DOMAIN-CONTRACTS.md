# Domain contracts

## Coding

### External review: Question Engineering

Trigger on qualified repeated friction, successful deviation, capability shifts, new constraints, contradictory standards, architecture pressure, verification failure, complexity accumulation, frontier discontinuity, or human challenge.

### System standard: Engineering Judgment

Owns optimization, tradeoffs, risk, change scope, evidence, authority, and uncertainty.

### Project model: Technical Truth

Owns the technical model, invariants and constraints, intentional decisions, technical direction, and local deviations.

## Product

### External review: Product Evolution

Trigger on qualified capability, behavior, economic, outcome, wedge, coherence, boundary, market/GTM, or human signals.

### System standard: Product Judgment

Owns outcome responsibility, coherence, wedges, capability translation, breadth, parallel bets, defaults, automation, interface versus agent behavior, build versus generate versus operate, evidence, removal, and authority.

### Project model: Product Model

Owns product thesis, actors and outcomes, transformed work, responsibility boundary, core model, value loops, topology, capabilities, wedges, bets, evidence, assumptions, constraints, direction, tensions, and non-goals.

## GTM

### External review: GTM Evolution

Trigger on qualified buyer, distribution, channel-economic, AI-capability, demand, wedge, sales-cycle, pricing, proof, competitive, product-usage, platform/regulatory, or human signals.

### System standard: Market Judgment

Owns market selection, wedges, audiences, offers, positioning, distribution, message-market fit, speed of contact, proof, sales compression, parallel experiments, coherence, economics, agent leverage, kill velocity, and authority.

### Project model: Market Position

Owns market thesis, targets, wedges, actors, offers, positioning, messages, channels, sales motion, pricing, proof, pipeline, experiments, conversion evidence, objections, competition, partnerships, constraints, bets, direction, and open questions.
