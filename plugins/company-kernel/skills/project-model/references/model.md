# Model judgment

Project context should preserve only what a capable model cannot safely infer, would infer incorrectly, or would waste meaningful time rediscovering.

`PROJECT.md` holds cross-domain identity, outcome, boundary, direction, and non-goals. `.kernel/NOW.md` holds fast-moving state. Domain models hold technical truth, product model, or market position.

Create a new file only when content changes at a different speed, belongs to a different authority, or has become too large to remain useful.
