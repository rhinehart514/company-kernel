# Research judgment

Research should improve a decision, not decorate a document.

Start with the unknown whose answer can change the most important choice.

Use first-party project evidence before generic market assumptions. Use current primary sources for facts that move.

Search for reasons the attractive story is wrong: failed attempts, trust barriers, regulation, poor economics, unreliable automation, distribution resistance, and human preference.

Translate every finding into its effect on the project model.

Stop when the next useful evidence is more likely to come from shipping, selling, observing, or testing.
