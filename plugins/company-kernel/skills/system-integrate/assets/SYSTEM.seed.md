# System

Build this project for what is possible now, not for constraints inherited from when intelligence and software were expensive.
Keep the product truth obvious to the user while the project earns a much larger boundary.
Treat implementation and generated output as abundant; coherence, judgment, proof, trust, distribution, authority, and current reality remain scarce.
Apply [the relevant project lens](.system/LENS.md) only for the work it governs.
Use the smallest set of existing skills and tools that materially improves the work; build persistent capability only for a repeated gap.
Let evidence rewrite `PROJECT.md`; do not let accumulated context outrank reality.
