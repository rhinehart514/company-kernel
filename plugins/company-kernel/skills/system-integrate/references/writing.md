# Writing

Write for a smart person moving quickly.

Lead with the truth or call. Use exact nouns, active verbs, short sections, and plain sentences.

System files contain one belief per line. Project files open with the simplest accurate truth. Capability maps explain ownership, not every installed object.

Delete framework setup, repeated explanation, generic reminders, and categories added for completeness.

State uncertainty plainly. Do not polish inference into fact.

Agent reports lead with project judgment and next proof. File operations come last.
