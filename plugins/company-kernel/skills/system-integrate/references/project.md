# Project compilation

Build project context after the shared system is ready.

Start with:

```text
PROJECT.md
.project/NOW.md
```

`PROJECT.md` should make clear what this is, what must become true, why now, who or what acts, how value is created, what the project owns, where it enters, what winning unlocks, and what it refuses to become.

`.project/NOW.md` holds the current objective, momentum, bets, constraints, contradictions, decisions in motion, and next proof.

Split more files only when content changes at a different speed, belongs to a different authority, or has become too large to stay useful.

Keep the entry and trajectory separate. Expansion should be earned through data, authority, trust, distribution, capability, economics, or system position.

Product, GTM, onboarding, delivery, and proof should describe the same promise.

Rewrite stale truth. Git stores history.
