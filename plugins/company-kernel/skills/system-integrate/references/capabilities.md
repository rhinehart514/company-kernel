# Capability judgment

A capability is the model, context, skill, access, and deterministic machinery needed to perform one repeated job well.

Resolve gaps in this order:

```text
current model
existing project and system context
installed skill
available tool or source
deterministic script or test
new skill
explicit limitation
```

## Calls

- **keep:** useful and correctly scoped
- **route:** strong but hard to activate or confused with another job
- **combine:** truly duplicated in trigger, judgment, authority, and result
- **rewrite:** useful but stale, bloated, or tied to an old model weakness
- **retire:** persistent context no longer improves behavior
- **build:** a repeated gap deserves a skill, script, adapter, or source
- **expose:** useful access exists but agents cannot reach or understand it
- **leave missing:** the capability cannot yet be supplied reliably

Prefer routing over merging when the distinction is uncertain.

Do not hide missing data or model ability behind more instructions.
