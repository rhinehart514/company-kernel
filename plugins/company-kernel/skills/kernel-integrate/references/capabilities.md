# Capability judgment

Judge the model, instructions, skills, tools, scripts, access, and connected evidence together.

Use the model for reasoning it already performs reliably. Use instructions for durable judgment. Use project files for current truth. Use a skill for repeated non-obvious work. Use a tool or connector for access and external action. Use a script for deterministic mechanics.

Names do not prove duplication. Missing access is not fixed with prose. One-time work is not a permanent capability.
