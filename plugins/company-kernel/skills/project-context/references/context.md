# Context shape

Start with `PROJECT.md` and `.project/NOW.md`.

Split more files only when one of these is true:

- the content changes much faster or slower
- a different person or source has authority over it
- only a narrow class of work needs the detail
- the root file has become hard to scan
- a high-stakes boundary deserves its own surface

Use names that match the project. Several files may cover one complex concern. Do not create placeholders for departments.

`PROJECT.md` should stay short enough to load for consequential work. It routes to detail instead of swallowing it.

`.project/NOW.md` can be rewritten aggressively. It is current state, not history.

Git stores the past. Project context stores the present.
