# Project writing

Open with the simplest accurate project truth.

Use short sections and direct claims. Put the actor beside the action and the evidence beside the claim.

Prefer “Relay completes security reviews” to “Relay is an AI-native platform for assurance transformation.”

Name observation, inference, bet, contradiction, and unknown when the distinction matters.

Do not add framework introductions, department inventories, duplicated system beliefs, or paragraphs that merely explain the heading.

Rewrite stale truth instead of adding a newer paragraph beneath it.
