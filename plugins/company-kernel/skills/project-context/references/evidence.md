# Evidence

Keep these distinctions clear:

```text
authorized direction  a decision someone had authority to make
observation            something directly seen or measured
inference              a conclusion drawn from evidence
bet                    a chosen risk under uncertainty
contradiction          evidence that does not fit the current model
unknown                a question that can still change direction
```

Code and tests support capability. Customer behavior supports demand. Sales behavior supports buying. Economic data supports viability. Agent synthesis is inference.

Use dates and provenance for claims that can go stale.

A request is not automatically strategy. A competitor launch is not customer need. A confident paragraph is not proof.
