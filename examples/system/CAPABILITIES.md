# Capabilities

**As of:** 2026-08-21

## Use

- `project-context`: compile and refresh current project truth
- `project-research`: resolve one project-shaping uncertainty
- `design-engineering`: implement interface and interaction work
- `product-design`: judge product behavior, boundaries, and user clarity

## Do not stack

- Use `product-design` before `design-engineering` when the product model itself is changing.
- Do not invoke several research skills for one shared-context question.

## Missing access

- Product analytics and support history are not connected. Product-state claims must remain qualified until that changes.
