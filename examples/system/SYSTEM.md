# System

Build for what current intelligence makes possible, not for workflows shaped by its scarcity.
Keep ambition large and the user's product model small.
Treat code, content, and research as abundant; coherence, judgment, proof, trust, distribution, authority, and reality are not.
Start where evidence and access are strongest; let each win earn the next boundary.
Use existing capabilities before adding instructions, skills, or tools.
Let current evidence rewrite beliefs and delete context that no longer helps.
Use [the lens index](LENSES.md) only when a task needs more judgment.
