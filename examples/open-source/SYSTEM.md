# System

Build Patchline for an agent-native software ecosystem, not for one coding client's session model.
Keep portable verified change evidence as the protocol truth while adoption expands into handoffs and automated review.
Treat code generation as abundant; interoperability, provenance, maintainer trust, and independent implementation remain scarce.
Apply [adoption](.system/ADOPTION.md) for ecosystem work and [maintainability](.system/MAINTAINABILITY.md) for protocol changes.
Prefer a small open protocol and strong reference tools to a hosted orchestration product.
Use current cross-client evidence to rewrite the project model; do not let vendor assumptions become protocol law.
