# Adoption

**As of:** 2026-08-21

## First adopters

Coding-agent maintainers, repository platforms, and open-source projects receiving large agent-generated changes.

## Proof

Independent implementations, successful interchange, verifier use in CI, and maintainers relying on the evidence instead of reopening the entire agent session.

## Distribution

Reference libraries, GitHub Actions, client integrations, open fixtures, and a public compatibility suite.

## Compounding asset

Every independent implementation improves protocol credibility. Every shared fixture lowers the cost of the next integration.

## Not this

Adoption should not depend on a hosted control plane owned by Patchline.
