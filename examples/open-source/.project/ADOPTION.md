# Adoption

**Purpose:** Keep ecosystem leverage explicit without importing a conventional sales file.

**As of:** 2026-08-21

## First adopters

Coding-agent maintainers, repository platform teams, and open-source projects receiving large volumes of agent-generated changes.

## Proof

Independent implementations, successful interchange, verifier use in CI, and maintainers relying on the evidence rather than reopening the entire agent session.

## Distribution

Reference libraries, GitHub Actions, client integrations, open test fixtures, and a public compatibility suite.

## Compounding asset

Each independent implementation improves protocol credibility. Each shared fixture lowers integration cost. Each accepted evidence package creates a stronger interoperability norm.

## Negative identity

Adoption should not depend on a hosted control plane owned by the project.
